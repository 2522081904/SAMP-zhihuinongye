# 页面编号映射（契约 ↔ 工程）

本文件用于消除两套页面编号口径的歧义：

- **契约口径**：`weekwork/spec_contract.md`「对应页面」列，来自需求说明书表 6.2，例如契约 `P002` = 工作台、契约 `P006` = 设备台账。
- **工程口径**：`src/router/` 中的 `meta.pageId` 与页面 `AgriPageHeader` 的 `page-id`，例如工程 `P002` = 环境数据监测、工程 `P006` = 设备巡检与离线排查。

约定：**UI 一律使用工程 pageId**（页面上的编号徽标、路由 `meta.pageId`、菜单排序都以工程口径为准）；接口契约原文不做修改，只在本文档内做映射说明。

## 认定的不一致条目

1. **契约 P002（工作台）≠ 工程 P002（环境数据监测）**：`A02` 的「对应页面」写作 `P001→P002`，指的是登录后进入工作台；工程没有独立的 PC 工作台页面，登录后实际跳转 `/iot/env`，落在工程 P002 环境数据监测。移动端工作台由工程 M001 承担。
2. **契约 P006（设备台账）→ 工程 P005（设备总览）**：`A03` 的台账查询对应工程 P005；工程 P006 是「设备巡检与离线排查」，两者职责不同，不能按编号直接对号入座。
3. **契约 P026 出现在 `A08`（阈值联动与策略）**：策略配置在工程 P008「策略联动配置」，工程 P026 是「告警处置与统计」；契约此处引用的是告警联动结果，属跨页语义，不是编号错误。
4. **契约 P027「周边」（`A24` 商品与客户档案）→ 工程 P028**：工程把商品与客户档案独立成 P028，P027 订单管理在页内引用客户/商品数据。
5. **工程存在但契约未引用的页面**：P005 设备总览（承载 A03 台账）、P013 视频监控、P019 库存与低库存预警、P028 商品与客户档案；这些页面的接口来自相邻契约条目或复用 A03/A24，后续补契约时建议显式登记。
6. **契约存在但工程无独立页面的口径**：契约 P002 工作台（见第 1 条），工程以登录后重定向 + 移动端 M001 替代。

> 说明：以上仅记录映射结论，`weekwork/spec_contract.md` 与路由 `meta.pageId` 均未修改。
